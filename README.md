# InsulinCalc — insulincalc.online

Калькулятор дозы инсулина и дневник диабета 1 типа. Статический сайт без собственного сервера:
браузер пользователя через Google OAuth (scope `drive.file`) пишет данные в **его собственную Google Таблицу**.

## Схема листа `Data`

Колонки листа (31, в порядке рабочей таблицы): `timestamp, user_id, event_type, event_subtype, target_glucose, current_glucose, uc, carbs_he, carbs_grams, compensation_dose, food_insulin, total_raw, dose_down, dose_up, selected_dose, rounding_choice, predicted_down, predicted_up, pause_minutes, pen_step, correction_factor, weight, glucose_2h, glucose_2h_timestamp, glucose_4h, glucose_4h_timestamp, notes, timestamp_w, timestamp_moscow, event_id, event_status`. Время: `timestamp` и `glucose_*_timestamp` — московское (`15.11.2026, 12:10`), от него считаются замеры через 2 и 4 ч (в т.ч. автозаполнение с сервера Juggluco); `timestamp_moscow` — местное время в часовом поясе, выбранном в начале расчёта (по умолчанию — пояс устройства; название поля временное), `timestamp_w` — то же время в UTC («время 0»). Статус после обоих замеров — `completed`. Числа записываются как числа, вводить можно через точку или запятую. Приём пищи распознаётся без учёта регистра и языка: `завтрак` = `breakfast`, `обед` = `lunch`, `ужин` = `dinner`. Старые записи с прежними названиями колонок читаются автоматически.
Глюкоза хранится в ммоль/л, углеводы — в граммах (и ХЕ). Лист `Settings` — настройки (ключ/значение).

## Настройки и активный инсулин

Постоянные параметры задаются в ⚙️ Настройках, расчёт — только ввод чисел:
- **Расчёт:** углеводы по умолчанию (ХЕ / граммы), количество грамм в 1 ХЕ (9–13 г), длительность действия болюсного (по умолчанию 2,5 ч) и базального (24 ч) инсулина.
- **Время:** часовой пояс («Авто» — пояс устройства). Местное время → `timestamp_moscow`, UTC → `timestamp_w`.
- **Общие:** язык, единицы глюкозы, допуск «в цели», имя, уведомления.

Активный инсулин = сумма болюсов за время действия, каждый убывает линейно: доза × (1 − прошло часов / длительность болюса). Базальный в него не входит — в меню отдельно показываются последняя доза, скорость (доза / длительность, ЕД/ч) и до какого времени действует. Из рассчитанной дозы активный инсулин автоматически не вычитается — это подсказка.

## Как считаются УК и ФЧИ в отчётах

Модель: Δглюкозы = (подъём на 1 ХЕ) × ХЕ − ФЧИ × доза; УК = (подъём на 1 ХЕ) ÷ ФЧИ. Код — `assets/js/stats.js`.

- **Какие события берутся.** Только с «чистым» замером: перед событием не действует предыдущий болюс (длительность болюса из настроек) и не было еды за 2 ч; между инъекцией и замером не было другого болюса или еды. Для подколок без еды берётся замер через 4 ч (если нет — 2 ч), для еды — через 2 ч (если нет — 4 ч).
- **ХЕ** пересчитываются из граммов по текущему весу 1 ХЕ из настроек. Для УК берутся события от 1 ХЕ.
- **Независимые.** ФЧИ = (глюкоза до − после) ÷ доза по подколкам без еды. УК = (доза + (после − до) ÷ ФЧИ) ÷ ХЕ по приёмам пищи, где глюкоза перед едой в пределах ±1,5 ммоль/л от цели. Медиана, выбросы отбрасываются.
- **По приёмам пищи.** УК — та же формула, медиана по событиям приёма (от 3 событий). Регрессия по одному приёму — только при 6+ событиях и R² ≥ 0,5. Опорный ФЧИ: чистые подколки (от 3) → общая регрессия → ФЧИ из самого расчёта.
- **Регрессия.** Общий ФЧИ и свой коэффициент углеводов у каждого приёма; приёмы меньше 1 ХЕ участвуют в оценке ФЧИ, но не в УК. УК — среднее по приёмам с учётом числа событий.
